# Accrete

A celestial action game about the way you choose to grow. Play it in your browser at **https://solvency-mechanism.github.io/accrete/**.

You start as a dwarf planet in an open star system where everything has momentum and gravity: gather matter, survive the bodies around you, and grow. A classic mode is behind the toggle on the title screen.

This repository holds only the built game, published from a private development repository. It is a work in progress.
